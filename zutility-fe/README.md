## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. 
3. Set backend integration vars in `.env.local`:
   `NEXT_PUBLIC_API_URL=http://127.0.0.1:3001`
   `NEXT_PUBLIC_WS_URL=ws://127.0.0.1:3001`
4. Run the app:
   `npm run dev`
